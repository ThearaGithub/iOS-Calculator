# iOS Calculator (Web)

A pixel-inspired clone of the iOS calculator built with plain HTML/CSS/JS.

## Features
- Authentic iOS look: round keys, orange operators, black display
- AC/C toggle, +/− sign, %, decimal input
- Operator chaining, repeated `=` (iOS behaviour)
- Active operator highlight (white bg / orange text)
- Thousands grouping & auto-shrinking display for long numbers
- Full keyboard support (digits, + - * /, Enter/=, %, Backspace, Esc)
- Responsive: full-screen on phones, centered card on desktop

## Run
Open `index.html` in a browser, or:
```bash
python3 -m http.server 8000
```
